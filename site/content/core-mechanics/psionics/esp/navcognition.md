title = "Navcognition"
attribute = "INT"

*This skill can't be used untrained.*

A character who uses this skill can instinctively determine his or her present location and mentally plot a course to a distant location. This can be accomplished on a planetary surface, in normal space, and even through drivespace, depending on how the character applies this skill.

This mental ability replaces the use of the **Navigation** skill (assuming the character has it) if the character decides to spend psionic energy points to activate it. All the modifiers that pertain to the use of the Navigation skill apply (see the "Navcognition Situation Modifiers" table below), except the character doesn't make use of charts, instruments, or computers to determine location and plot courses.

| Situation Modifier | Value |
| :--- | :---: |
| Combat conditions | +4 |
| Hostile conditions | +2 |
| Calm conditions | 0 |
| Unexplored territory | +4 |
| Partially explored territory | +2 |
| Known territory | 0 |
| Familiar territory | –2 |
| Less than 5 minutes | +1/min. |
| More than 5 minutes | –1/min. |

For surface navigation only:
- Darkness: +3
- Inclement weather: +2
- Rough terrain/turbulence: +2

#### Travel Time
For surface navigation and system astrogation, a skill check determines travel time:

| Result | Modifier |
| :--- | :---: |
| Critical Failure | x1.5 |
| Failure | x1 |
| Ordinary | x0.9 |
| Good | x0.75 |
| Amazing | x0.5 |

*Drivespace astrogation works differently, as all trips through drivespace typically last the same amount of time. Instead, a travel distance modifier may be applied (see below).*

#### Travel Distance
| Result | Modifier |
| :--- | :---: |
| Critical Failure | x0.5 |
| Failure | x1 |
| Ordinary | x1.25 |
| Good | x1.5 |
| Amazing | x2 |

**Rank Benefits:**
- **At rank 1**, the character selects one specialty of the Navigation skill to which to apply this mental ability: either **Surface Navigation**, **System Astrogation**, or **Drivespace Astrogation**.
- **At rank 4, 8, and 12 [Travel Time]**, the character becomes able to determine the clearest way to the destination.
- **At rank 5 [Extra Specialty Skills]**, a second Navigation specialty can be selected.
- **At rank 6 [Clarity of Mind]**, the character can apply this skill toward navigating under extreme conditions, seeing the best route from point A to point B through even the chaos of battle. This allows the character a –4 step bonus to the appropriate navcognition skill checks during chases, races, or vehicle combat.
- **At rank 9**, the remaining specialty becomes available.
- **At rank 12 [Tracking]**, a character may use navcognition to attempt to track the most likely destination of a target subject. This ability may even be attempted through drivespace.
