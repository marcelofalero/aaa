*Esta habilidad no puede usarse sin entrenamiento.*

Un personaje que utiliza esta habilidad puede determinar instintivamente su ubicación actual y trazar mentalmente un curso hacia un lugar distante. Esto puede lograrse en la superficie de un planeta, en el espacio normal e incluso a través del espacio de curvatura (drivespace), dependiendo de cómo el personaje aplique esta habilidad.

Esta capacidad mental reemplaza el uso de la habilidad de **Navegación** (asumiendo que el personaje la posea) si el personaje decide gastar puntos de energía psiónica para activarla. Se aplican todos los modificadores que pertenecen al uso de la habilidad de Navegación (consulta la tabla de "Modificadores de Situación de Navcognición" a continuación), excepto que el personaje no hace uso de cartas, instrumentos o computadoras para determinar la ubicación y trazar cursos.

| Modificador de Situación | Valor |
| :--- | :---: |
| Condiciones de combate | +4 |
| Condiciones hostiles | +2 |
| Condiciones de calma | 0 |
| Territorio inexplorado | +4 |
| Territorio parcialmente explorado | +2 |
| Territorio conocido | 0 |
| Territorio familiar | –2 |
| Menos de 5 minutos | +1/min. |
| Más de 5 minutos | –1/min. |

Solo para navegación de superficie:
- Oscuridad: +3
- Clima inclemente: +2
- Terreno difícil/turbulencia: +2

#### Tiempo de Viaje
Para la navegación superficial y la astrogación de sistema, una tirada de habilidad determina el tiempo de viaje:

| Resultado | Modificador |
| :--- | :---: |
| Fallo Crítico | x1.5 |
| Fallo | x1 |
| Ordinario | x0.9 |
| Bueno | x0.75 |
| Asombroso | x0.5 |

*La astrogación en el espacio de curvatura (drivespace) funciona de manera diferente, ya que todos los viajes a través de este suelen durar la misma cantidad de tiempo. En su lugar, se puede aplicar un modificador de distancia de viaje (ver a continuación).*

#### Distancia de Viaje
| Resultado | Modificador |
| :--- | :---: |
| Fallo Crítico | x0.5 |
| Fallo | x1 |
| Ordinario | x1.25 |
| Bueno | x1.5 |
| Asombroso | x2 |

**Beneficios de Rango:**
- **Al rango 1**, el personaje selecciona una especialidad de la habilidad de Navegación a la cual aplicar esta capacidad mental: ya sea **Navegación de Superficie**, **Astrogación de Sistema** o **Astrogación de Espacio de Curvatura (Drivespace)**.
- **Al rango 4, 8 y 12 [Tiempo de Viaje]**, el personaje se vuelve capaz de determinar el camino más despejado hacia el destino.
- **Al rango 5 [Habilidades de Especialidad Adicionales]**, se puede seleccionar una segunda especialidad de Navegación.
- **Al rango 6 [Claridad de Mente (Clarity of Mind)]**, el personaje puede aplicar esta habilidad para navegar bajo condiciones extremas, viendo la mejor ruta del punto A al punto B incluso a través del caos de la batalla. Esto permite al personaje una bonificación de –4 pasos a las tiradas de habilidad de navcognición apropiadas durante persecuciones, carreras o combate de vehículos.
- **Al rango 9**, la especialidad restante queda seleccionable.
- **Al rango 12 [Rastreo (Tracking)]**, un personaje puede usar la navcognición para intentar rastrear el destino más probable de un sujeto objetivo. Esta habilidad incluso puede intentarse a través del espacio de curvatura (drivespace).
