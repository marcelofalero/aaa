*Duración extendida.*
*Esta habilidad no puede usarse sin estar entrenado.*

Esta especialidad consiste en la capacidad de vincular la propia mente con una computadora (o una máquina cibernética, si se utilizan las reglas opcionales para ciberequipos) sin necesidad de utilizar ningún tipo de conexión física. La habilidad de enlace de datos puede utilizarse para manejar computadoras o maquinaria cibernética con órdenes mentales, para proyectar la propia mente en el flujo de datos sin necesidad de una conexión de interfaz neuronal (NIJack) o de un proyector matricial, o para examinar datos informáticos escaneando mentalmente la unidad de almacenamiento.

En términos de juego, el personaje es capaz de utilizar las mismas funciones proporcionadas por un sistema operativo de computadora (tal y como se describe en el *Manual del Jugador*, Capítulo 10: Computadoras): copiar, borrar, reconocimiento de errores, gestión de archivos, protección, protocolo y guardar.

Una vez dentro del flujo de datos, una mente con ciberenlace puede desplazarse por todo un sistema informático en red. Para iniciar el enlace, el personaje debe realizar una tirada de la especialidad de **Telepatía—enlace de datos**.

**Enlace de Datos frente a Ciberequipo:**
Un telépata audaz con la habilidad de enlace de datos podría intentar hackear el ciberequipo de otro personaje y utilizarlo contra él. Para ello, el telépata debe obtener primero acceso a la nanocomputadora del equipo mediante Telepatía—enlace de datos. Si el equipo no incluye una nanocomputadora, no es posible el hackeo telepático. (La Tabla P53: Ciberequipo del *Manual del Jugador* indica qué ciberequipo requiere una nanocomputadora). El uso de este tipo de "ataque" se considera una violación escandalosa por parte de los mechalus.

A continuación, el telépata puede manejar el ciberequipo como si fuera su usuario, realizando tiradas de enlace de datos por cada acción que desee que realice el ciberequipo. Hay una penalización a esta tirada basada en el modificador de resistencia de Voluntad del propietario real, si éste se resiste conscientemente al control externo de sus piezas cibernéticas. Además, existen modificadores basados en el tipo de acción que el psiónico desee forzar a realizar al ciberequipo:

| Acción | Modificador |
| :--- | :---: |
| Encendido/apagado | –1 |
| Obstaculizar al usuario (+1 a las tiradas de habilidad del usuario) | ninguno |
| Debilitar al usuario (+3 a las tiradas de habilidad del usuario) | +2 |
| Atacar al usuario (sólo posible con ciberarmas) | +4 |

Las penalizaciones a las tiradas de habilidad del usuario del ciberequipo sólo se aplican a las tiradas de habilidad que empleen el ciberequipo.

**Beneficios de Rango:**
- **Al rango 4 [Duración Extendida (Extended Duration)]**, la unidad de duración del enlace de datos es de 1 minuto, que se amplía un minuto más por cada punto de energía psiónica gastado para ello.
- **Al rango 8 [Duración Extendida (Extended Duration)]**, la duración se amplía a 5 minutos, y al rango 12, se amplía a 30 minutos.
