A character with this perk can use both hands at the same time with more ease than someone who is not ambidextrous. A character without this perk suffers penalties when using his off hand or when attempting to use two weapons in combat. (See “Attacking with Two Weapons" on page 57 in Chapter 3: characters in Action.) With this perk, the penalty for the action using the off hand is reduced to +2 steps, and the penalty for the primary hand is eliminated.
