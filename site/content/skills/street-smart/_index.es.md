Esta amplia habilidad proporciona a Personaje un conocimiento general de los protocolos de "la calle". Mide la capacidad de un Personaje para negociar y establecer contacto con el ámbito de los delitos manuales, las pandillas y los traficantes ilícitos. Callejeo y sus especialidades son las habilidades de encuentro.

## Habilidades de Especialidad
{{< specialty attr="INT" untrained="yes" cost="3" >}}

Esta habilidad permite a un Personaje mejorar su familiaridad con el funcionamiento interno de una organización o área geográfica en particular. A diferencia de las especialidades Otros, se debe comprar por separado para cada organización o área (por ejemplo, **Street Knowledge—Alpha Colony** o
**Conocimiento callejero: The Void Syndicate**). Un Personaje necesita comprar esta especialidad dos veces para familiarizarse con cómo se hacen las cosas en una organización interestelar o sindicato interestelar específico.

---

## Criminal elements
{{< specialty attr="WIL" untrained="yes" cost="5" >}}

Este Especialidad representa la capacidad de un Personaje para establecer contacto y tratar con aquellos que se consideran parte del elemento criminal: crimen organizado, delincuentes profesionales, pandillas callejeras y organizaciones del hampa. Siempre que un Personaje intenta localizar o interactuar con estos grupos, utiliza esta habilidad.
