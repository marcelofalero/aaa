*This skill can't be used untrained.*

This specialty skill represents the ability to command by example. It is used to favorably alter the attitude of the target(s) toward the user of the skill.

Unlike command, inspire can be used on targets who are Hostile or Combative.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates as many as two followers receive the leadership bonus. |
| **Good** | Success indicates as many as four followers receive the leadership bonus. |
| **Amazing** | Success indicates as many as six followers receive the leadership bonus. |
