This specialty skill enables a hero to analyze computer programs, modify existing programs, and create programs by writing her own code.

Having rank 1 in this skill enables a character to modify the source code of programs of Ordinary quality and Ordinary complexity.

### Rank Benefits
- **Modify Existing Programs:** At rank 3, able to modify code of programs of Good quality and Good complexity. At rank 6, can modify any existing program.
- **Create New Programs:** At rank 3, create new programs of Marginal quality and Marginal complexity. Ordinary programs at rank 6, Good programs at rank 9, and Amazing programs at rank 12.
