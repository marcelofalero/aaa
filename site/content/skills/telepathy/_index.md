*This skill can't be used untrained.*

This broad skill allows a character to open his mind to the thoughts of others or send his own thoughts into the minds of others.

## Specialty Skills

### Contact (PER)

*Extended duration.*

Send and receive thoughts with another character. Unwilling targets apply their Will resistance modifier as a penalty and can expel the user.

#### Results
- **Ordinary:** Simple concepts (brief questions/one-word answers).
- **Good:** Moderate discussion (pass notes every 2 phases).
- **Amazing:** Detailed discussion (vocally conversing).

#### Distance/Mind Modifiers
- **Familiar mind:** -1; **Unfamiliar mind:** none; **Combative:** +2; **Hostile:** +1.
- **1-10m:** -1; **11-100m:** none; **101m-1km:** +1; **2-10km:** +2; **11-100km:** +3; **101-1,000km:** +4; **1,001-10,000km:** +5.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates simple thought exchange. |
| **Good** | Success indicates moderate discussion. |
| **Amazing** | Success indicates detailed discussion. |

### Datalink (PER)

*Extended duration. This skill can't be used untrained.*

Link mind with a computer or cybernetic machine without physical connection. Operates machines, projects mind into datastream, or scans storage.

#### Proximity Modifiers
User must be within 6 meters:
- **Up to 2m:** none
- **2-4m:** +1 penalty
- **4-6m:** +2 penalty
Normal computer defenses apply as a penalty.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates linking with the machine. |
| **Good** | Success indicates linking with the machine. |
| **Amazing** | Success indicates linking with the machine. |

### Illusion (PER)

*Extended duration.*

Project illusory sight or sound into a target's mind. Usable only against visible targets; range 5 meters per skill rank. Maintaining an illusion gives a +1 penalty to other actions.

#### Results
Check result determines penalty to target's Awareness-intuition check to realize it's an illusion:
- **Ordinary:** +1
- **Good:** +2
- **Amazing:** +3
Multiple targets provide a cumulative +1 penalty per additional target.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates projecting an illusion. |
| **Good** | Success indicates projecting an illusion. |
| **Amazing** | Success indicates projecting an illusion. |

### Mind Blast (PER)

*This skill can't be used untrained.*

Direct a blast of pure mental energy at another mind in visual contact (range 10/20/40). Armor does not protect against a mind blast.

#### Results
- **Ordinary:** d4+1s/d4+2s/d6+2s.
- **Good:** d4+1s/d4+2s/d6+2s.
- **Amazing:** d4+1s/d4+2s/d6+2s.

#### Rank Benefits
- **Rank 5 [Increased Damage]:** d4+2s/d6+2s/d8+2s.
- **Rank 9 [Increased Damage]:** 2d4+2s/2d6+2s/2d8+2s.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates causing mind blast damage. |
| **Good** | Success indicates causing mind blast damage. |
| **Amazing** | Success indicates causing mind blast damage. |

### Mind Shield (PER)

Establish a mental defense against specific psionic powers: contact, empathy, illusion, mind reading, mind blast, suggest, and tire.

#### Results
Check result determines penalty to opponent's skill check:
- **Ordinary:** +1
- **Good:** +2
- **Amazing:** +3
Remains in place for 5-8 hours (d4+4) or until it fails to stop a power.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates the shield provides +1 penalty to opponents. |
| **Good** | Success indicates the shield provides +2 penalty to opponents. |
| **Amazing** | Success indicates the shield provides +3 penalty to opponents. |

### Suggest (PER)

Plants a thought into another person's mind and convinces them it's their own. Cannot have permanent or immediately detrimental effects.

#### Results
Check result determines duration:
- **Ordinary:** 1 hour
- **Good:** 2 hours
- **Amazing:** 3 hours
Target makes a Will feat check after it wears off to realize it was a suggestion (penalty/bonus is reverse of original skill check modifier).
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates the suggestion lasts for 1 hour. |
| **Good** | Success indicates the suggestion lasts for 2 hours. |
| **Amazing** | Success indicates the suggestion lasts for 3 hours. |

### Tire (PER)

Inflict fatigue damage on a target in visual contact (range 10/20/30).

#### Results
- **Ordinary:** 1 fatigue point
- **Good:** 2 points
- **Amazing:** 3 points
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates inflicting 1 fatigue point. |
| **Good** | Success indicates inflicting 2 fatigue points. |
| **Amazing** | Success indicates inflicting 3 fatigue points. |
