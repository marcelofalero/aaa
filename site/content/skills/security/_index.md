*This skill can't be used untrained.*

This broad skill pertains to security systems that protect physical objects or defined areas. Systems for computerized data are dealt with under Hacking.

### Complexity
- **Marginal:** Hero is undisturbed and familiar with the system.
- **Amazing:** Hero is in combat or under severe time pressure.

## Specialty Skills

### Security Devices
Using this skill, a hero can attempt to bypass all types of mechanical or electronic security, from trip wires to motion sensors to electronic locks. It's also used to set traps, both electronic and mechanical in nature.

One check can be made per round (or per minute in non-combat situations), and the hero is busy for the entire period.

### Protection Protocols
This skill represents training in protection procedures of all types.

#### Secure an Area
With time and cooperation, a hero can set defenses. The success affects subsequent Awareness checks of guards:
- **Critical Failure:** +1 penalty
- **Failure:** no modifier
- **Ordinary:** -1 bonus
- **Good:** -2 bonus
- **Amazing:** -3 bonus

#### Analyze Weak Points
Study a secured area for weak points to exploit. The analysis check is modified by the area's security:
- **No security:** no modifier
- **Marginal:** +1 penalty
- **Ordinary:** +2 penalty
- **Good:** +3 penalty
- **Amazing:** +4 penalty
Success provides bonuses to subsequent skill checks to force entry: Ordinary: -1; Good: -2; Amazing: -3.
