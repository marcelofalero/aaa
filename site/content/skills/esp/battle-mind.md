*Extended duration. This skill can't be used untrained.*

Focus on the battle at hand. Success gives a bonus to action checks:
- **Ordinary:** -1
- **Good:** -2
- **Amazing:** -3
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates -1 to action checks. |
| **Good** | Success indicates -2 to action checks. |
| **Amazing** | Success indicates -3 to action checks. |
