*This skill can't be used untrained.*

This skill allows a character to experience his environment through an agency beyond normal senses (Extrasensory Perception).

## Specialty Skills

{{% list %}}
- **Battle Mind:** Focus on battle for bonuses to action checks.
- **Clairaudience:** Hear sounds at a distant location.
- **Clairvoyance:** See images at a distant location.
- **Empathy:** Read surface emotions of another character.
- **Mind Reading:** Read surface thoughts of another character.
- **Navcognition:** Instinctively determine location and plot courses.
- **Postcognition:** Sense mood and "see" recent past events.
- **Precognition:** Receive impressions about possible future events.
- **Psychometry:** Read psychic impressions from inanimate objects.
- **Sensitivity:** Consciously detect psionic use in vicinity.

### Empatía
Read surface emotions of another character in visual contact. Assists in encounter situations.

### Results
Provides understanding of emotional state (Combative, Hostile, Neutral, Friendly, Charmed, Fanatic) and a bonus when using encounter skills: -1 or -3 steps.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates reading the target's emotions. |
| **Good** | Success indicates reading the target's emotions. |
| **Amazing** | Success indicates reading the target's emotions. |

### Mente de batalla
*Extended duration. This skill can't be used untrained.*

Focus on the battle at hand. Success gives a bonus to action checks:
- **Ordinary:** -1
- **Good:** -2
- **Amazing:** -3
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates -1 to action checks. |
| **Good** | Success indicates -2 to action checks. |
| **Amazing** | Success indicates -3 to action checks. |

### Psicometría
Read psychic impressions from inanimate objects through touch. Tools, weapons, clothing, and dead bodies can be studied. Living creatures or casually encountered objects (dirt) are not affected.

### Results
- **Ordinary:** Simple emotions associated with object.
- **Good:** Simple images associated with object.
- **Amazing:** Brief encounter as though the hero were the person using the object.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates reading simple emotions. |
| **Good** | Success indicates reading simple images. |
| **Amazing** | Success indicates a brief encounter as though the hero were the person using the object. |

### Sensibilidad
Consciously realize when a psionic skill is being used in the vicinity. Costs 2 energy points to activate; lasts 1 minute. Maintain for 1 pt/minute.

### Results
- **Ordinary:** Aware of psionic skill within 20m and identifying the source character.
- **Good:** Identify the broad skill(s) being used.
- **Amazing:** Identify the exact specialty skill(s) being used.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates awareness of psionic use within 20m. |
| **Good** | Success indicates identifying the broad skill(s). |
| **Amazing** | Success indicates identifying the exact specialty skill(s). |

### Cognición de navegación
*This skill can't be used untrained.*

Instinctively determine present location and mentally plot courses without charts or instruments. Replaces Navigation skill.

### Rank Benefits
- **Rank 1:** Select one specialty: surface, system astrogation, or drivespace astrogation.
- **Rank 5:** Select a second specialty.
- **Rank 9:** Final specialty becomes available.

| :--- | :--- |
| **Ordinary** | Success indicates plotting a course. |
| **Good** | Success indicates plotting a course. |

### Clariaudiencia / Clarividencia
Select a location and project your mind to that spot to hear sounds (Clairaudience) or see images (Clairvoyance).

### Rules
- **Duration:** Ordinary: 1 round; Good: 2 rounds; Amazing: 3 rounds. Extend for 1 psionic energy point per round.
- **Constraints:** Does not block normal senses (double vision/sound). Clairvoyance must be to an unobstructed location.

### Distance Modifiers
- **Familiar:** -1; **Unfamiliar:** none.
- **1-10m:** -1; **11-100m:** none; **101m-1km:** +1; **2-10km:** +2; **11-100km:** +3; **101-1,000km:** +4; **1,001-10,000km:** +5.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates the projection lasts for 1 round. |
| **Good** | Success indicates the projection lasts for 2 rounds. |
| **Amazing** | Success indicates the projection lasts for 3 rounds. |

### Postcognición / Precognición
Receive impressions about the past (Postcognition) or future (Precognition).

### Results
- **Ordinary:** Sense general emotions (past) or vague images (future).
- **Good:** Brief flashes of events.
- **Amazing:** Brief encounter as though at the scene.

### Postcognition
See time units (hours/days) into the past equal to skill rank.

### Precognition
See time units (hours/days) into the future equal to skill rank. Usually GM-triggered.
- **Forcing a flash:** Cost is doubled (2/4/6 pts); +3 penalty; cannot use consciously again for 2d6 days.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates vague images/emotions. |
| **Good** | Success indicates brief flashes. |
| **Amazing** | Success indicates a brief encounter as though at the scene. |
