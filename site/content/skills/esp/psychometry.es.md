Read psychic impressions from inanimate objects through touch. Tools, weapons, clothing, and dead bodies can be studied. Living creatures or casually encountered objects (dirt) are not affected.

### Results
- **Ordinary:** Simple emotions associated with object.
- **Good:** Simple images associated with object.
- **Amazing:** Brief encounter as though the hero were the person using the object.
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates reading simple emotions. |
| **Good** | Success indicates reading simple images. |
| **Amazing** | Success indicates a brief encounter as though the hero were the person using the object. |
