*Extended duration.*

Move objects with the mind. Lift up to Will x 10 kg; push up to Will x 20 kg. Figures are doubled in light gravity and halved in heavy gravity.

### Results (Lift / Push per phase in meters)
- **Ordinary:** 1 / 2
- **Good:** 2 / 4
- **Amazing:** 3 / 6
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates moving object at 1m lift / 2m push. |
| **Good** | Success indicates moving object at 2m lift / 4m push. |
| **Amazing** | Success indicates moving object at 3m lift / 6m push. |
