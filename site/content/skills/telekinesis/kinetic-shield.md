*Extended duration. This skill can't be used untrained.*

Create an invisible defensive barrier that moves with the hero, providing protection from physical attacks. Maintaining the shield gives a +1 penalty to other actions.

### Results
- **Ordinary:** HI +1 / LI +2
- **Good:** HI +2 / LI +3
- **Amazing:** HI +3 / LI +4
| Results | Description |
| :--- | :--- |
| **Ordinary** | Success indicates the shield provides HI +1 / LI +2. |
| **Good** | Success indicates the shield provides HI +2 / LI +3. |
| **Amazing** | Success indicates the shield provides HI +3 / LI +4. |
