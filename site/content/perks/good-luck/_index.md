A character with the Good Luck perk can make use of this benefit once during a scene. Immediately before attempting some other type of action (usually a skill check, an action check, or a feat check), the character can make a Good Luck perk check. The result of this check provides a modifier to the next activity the character undertakes: On a Critical Failure, bad luck occurs instead, and the character takes a +3 penalty. On a Marginal success, his next activity receives a -1 bonus; Ordinary, -2 bonus; Good, -3 bonus; and Amazing, -4 bonus.
