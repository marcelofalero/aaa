Teach (WIL)

This broad skill represents a hero’s ability to instruct others in Open group skills.

Results

Instruction from a teacher can decrease the cost for a character when buying or improving a skill. A teacher can only teach skills he possesses, and can only teach a specialty up to one-half his current rank.

  • Critical Failure: student doesn’t learn or improve at this time.
  • Failure: student must pay full skill cost.
  • Ordinary: student pays cost -1.
  • Good: student pays cost -2.
  • Amazing: student pays cost -3.

Specialty Skills

  • Teach [Specific Field]
  • Teach, Specific Field: Ability to teach skills associated with a profession.
