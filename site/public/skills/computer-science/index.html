Computer Science (U) (INT)

This skill can’t be used untrained (except for some user-friendly systems).

The broad skill provides a hero with a basic understanding of computers and computer systems. The three primary uses are information retrieval, computer repair, and programming.

Information Retrieval

Searching for information requires a skill check only if it is protected or obscure. A hero with just the broad skill can only access programs of Marginal quality/complexity in protected systems.

Computer Repair

Repairing a computer system is always a complex skill check.

Programming

A hero with just the broad skill can only manipulate the source code of programs of Marginal quality and Marginal complexity.

Specialty Skills

  • Hacking
  • Hardware
  • Programming
