System Operation (U) (INT)

This skill can’t be used untrained.

This broad skill provides basic training in spaceship systems, ground-based installations, and other vehicles like battleships or cargo ships.

Specialty Skills

  • Communications
  • Defenses
  • Engineering
  • Sensors
  • Weapons
Specialty Description
Communications Operate comm gear, decipher signals, code messages, jam signals.
Defenses Operate defensive systems, direct defense to ship parts, analyze attack patterns.
Engineering Monitor electronic/mechanical systems, institute repairs from station, route power.
Sensors Operate sensor gear, scan ships/planets, analyze readings for bonuses.
Weapons Operate shipboard weapons systems, pick targets, make attacks.
