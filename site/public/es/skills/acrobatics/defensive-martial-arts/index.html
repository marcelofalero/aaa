Artes marciales defensivas (U) (DEX)

This skill can’t be used untrained.

This specialty skill encompasses styles such as aikido and tai chi chuan, focusing on fluid, circular movements to redirect an attacker’s force.

A character can use throws, sweeps, flips, and holds to cause stun damage (d4s/d4+1s/d4+2s, LI). It may also enable a hero to knock an opponent to the ground.

Rank Benefits

  • Rank 2 [Block]: Attempt to block or counter an unarmed attack. The success must be equal to or greater than the attacker’s success. Requires an available action in the current phase.
  • Rank 4 [Reaction Block]: Attempt to block whenever any unarmed attack is directed against the hero, using the character’s next available action (in the current or following round).
  • Rank 4, 8, 12 [Resistance Modifier]: The hero’s Strength resistance modifier improves by +1 at each of these ranks.
