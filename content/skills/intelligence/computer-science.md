# Computer Science (INT) (U)

*Cannot be used untrained.*

Basic understanding of computers and systems. Essential for any task beyond simple operation at PL 5 or higher.

- **Information Retrieval:** Search for protected or obscure data.
- **Computer Repair:** Fix damaged systems (Complex Check).
- **Programming:** Modify or navigate source code.

## Specialty Skills

### Hacking (U)
*Cannot be used untrained.*
Break codes and bypass security to access restricted data or sabotage systems.
- **Rank 4, 8, 12:** -1 situational bonus to hacking actions.

### Hardware
Knowledge of physical computer components. Used for building, setting up, and repairing hardware.
- **Rank 4, 8, 12:** -1 situational bonus to hardware repair.

### Programming
Analyze, modify, and create computer programs.
- **Modify Existing:** Rank 1 (Ordinary), Rank 3 (Good), Rank 6 (Any).
- **Create New:** Rank 3 (Marginal), Rank 6 (Ordinary), Rank 9 (Good), Rank 12 (Amazing).
