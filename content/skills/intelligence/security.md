# Security (INT) (U)

*Cannot be used untrained.*

Knowledge of security systems protecting physical objects or areas. (Data security is handled by Computer Science).

## Specialty Skills

### Protection Protocols
- **Secure an Area:** Success penalizes Awareness checks of those trying to intrude.
- **Analyze Weak Points:** Study an area to find exploits for future entry or stealth checks.

### Security Devices
Bypass electronic and mechanical locks, motion sensors, and trip wires. Also used to set traps.
