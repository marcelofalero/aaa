# Technical Science (INT) (U)

*Cannot be used untrained.*

Training in maintenance, repair, and invention. Necessary for using dangerous high-tech tools safely.

## Specialty Skills

### Invention
Build or modify components from scratch. Almost always a complex skill check taking hours to months.

### Juryrig
Patchwork repairs to get systems running quickly for a short time. 
- **Check Time:** Must be first action in a round.
- **Duration:** Ordinary (d6+1), Good (2d4+2) time units.
- **Cost:** Adds difficulty to subsequent full repairs.

### Repair
Perform permanent repairs on damaged systems. (Computer repair uses Hardware specialty).
