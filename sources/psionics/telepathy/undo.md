name: Undo

With this skill, a telepath can reverse the effects of a successful use of
Telepathy-illusion, mind wipe, or suggest. The telepath must achieve a better
result than the user of the original telepathic skill, with a +1 step modifier
per rank of difference if the original user's rank is higher, or a
-1 step modifier per rank of difference if the original user's rank is lower. Only one attempt is allowed each day.
