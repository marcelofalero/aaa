# Gemini CLI Project Mandates

Please strictly follow the guidelines established in the `site/AGENTS.md` file for this project. 

Specifically:
- Terminology must follow `site/content/notes/terminology-mapping.md`.
- Code changes must use the `gh` CLI workflow (branch, commit, PR).
- Specialty skills must be self-contained and not rely on broad cross-references for rank benefits.
- "Character" should always be used instead of "hero".
